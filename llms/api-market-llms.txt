# API Market

> API.market is a comprehensive marketplace for APIs and AI models, offering 600+ APIs with 99.9% uptime and serving over 170 million monthly requests. The platform specializes in AI-powered APIs including image generation, video processing, face swapping, mapping, and data processing tools, designed for developers and businesses seeking reliable, scalable API solutions.

API.market operates as a fully managed marketplace where developers can discover, integrate, and scale with powerful APIs. The platform features customer-driven development, ensuring all models address real business needs, and maintains enterprise-grade infrastructure capable of handling over 170 million API calls per month with 99.99% uptime.

Key platform features include API Playground for testing, comprehensive OpenAPI specifications, MCP (Model Context Protocol) server support, pay-as-you-go pricing, and free tier offerings. The platform is highly automated and designed for scalability, supporting both individual developers and enterprise customers.

## MCP Configuration

API Market APIs support MCP (Model Context Protocol) for AI assistant integration. Each API includes MCP server configuration:

```json
{
  "mcpServers": {
    "api_market_[provider]_[api_name]": {
      "url": "https://prod.api.market/api/mcp/[workspace]/[product]",
      "headers": {
        "x-api-market-key": "YOUR_API_MARKET_KEY"
      }
    }
  }
}
```

Access any API through MCP-compatible AI tools by using the configurations provided on each API's product page.
